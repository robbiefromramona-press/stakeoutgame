# video/ — not part of the game

`stakeoutgame` is the Stake-Out simulator. This folder is a **starter kit for a
different repo**, parked here because it was produced on the
`claude/totalstationtech-setup-images-rocq9o` branch and had to land somewhere.

`tst-video-starter/` is the scaffold for a TotalStationTech video pipeline —
Remotion + Stable Diffusion — including the image prompt pack for episode 001,
"What Is a Setup?".

**Nothing in here is loaded by the game.** No file outside this folder references it,
and no file in it references the game.

Start at [`tst-video-starter/SETUP.md`](tst-video-starter/SETUP.md). Once the new
`totalstationtech-video` repo exists and this has been copied into it, this folder can
be deleted from stakeoutgame without losing anything.
